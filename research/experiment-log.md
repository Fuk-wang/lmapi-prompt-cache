## 两条从数据里读出来的结论

**1）命中长度 ≈ 第一个差异出现的位置，且按 64 token 对齐。**

| 差异位置（按字符） | 命中 tokens | 命中率 | 命中 tokens ÷ 64 |
|---|---:|---:|---:|
| 11% | 128 | 4.8% | 2.0 |
| 31% | 640 | 24.0% | 10.0 |
| 51% | 1152 | 43.2% | 18.0 |
| 76% | 1792 | 67.2% | 28.0 |
| 96% | 2304 | 86.5% | 36.0 |

五次命中值全部是 64 的整数倍（128 / 640 / 1152 / 1792 / 2304），说明缓存命中以 64 token 为一个单位向下取整。

**2）前缀里改一个词，命中直接归零。**
把 `返利结构` 改成 `返利机制`（出现在文档前段）后：prompt=2665，hit=0，miss=2665，命中率 0.0% —— 因为差异之后的前缀全部作废。
